# zaidd 

just your avg high school student, currently working on some math research, neuroscience, early chronic kidney disease detection, and my own little game

- **[neural-codes-96](https://github.com/NotItsMe/neural-codes-96):** settled 81 of the 96 open neural codes from Remark 2.33 of arXiv:2510.20323. Exact certificates, a checker, and a [3D viewer](https://notitsme.github.io/neural-codes-96/).
- **[neural-codes](https://github.com/NotItsMe/neural-codes):** the toolkit and raw results behind it.
- **[ckd-albuminuria-screening](https://github.com/NotItsMe/ckd-albuminuria-screening):** part of my work on catching chronic kidney disease early, at stage 1–2, before it shows up in blood tests. Ranks who should get a urine albumin test using routine checkup data (NHANES 2011–2023). Code for my paper *The Urine Test Nobody Orders*.
- **Kosmon:** a space-themed collectible card game I build and run.
- **Big Bee Brain:** a study site for the Brain Bee neuroscience competition.
